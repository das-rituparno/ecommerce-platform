# E-Commerce Platform

A production-style e-commerce application built using
Java, Spring Boot, Angular, MySQL, Kafka, Redis and
microservices architecture.

## Project Goals

- Build a complete e-commerce workflow
- Practice Spring Boot
- Practice microservices architecture
- Implement event-driven architecture using Kafka
- Implement caching using Redis
- Implement authentication and authorization
- Practice distributed transactions
- Implement CI/CD
- Deploy the application
- Prepare for backend Java interviews

## Architecture

The project will progressively evolve from a simple
Spring Boot application into a microservices architecture.

## Technologies

- Java
- Spring Boot
- Spring Security
- MySQL
- Angular
- Kafka
- Redis
- Spring Cloud
- Docker
- Jenkins
