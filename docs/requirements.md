# E-Commerce Platform — Requirements

## 1. Project Overview

The E-Commerce Platform is an online shopping application
where customers can browse products, manage their cart,
place orders, make payments, and track their orders.

The platform will also provide administrative capabilities
for managing products, categories, inventory, and orders.

## 2. User Roles

### Customer

A customer can:

- Register
- Login
- Browse products
- Search products
- Filter products
- View product details
- Add products to cart
- Remove products from cart
- Manage wishlist
- Manage addresses
- Checkout
- Place orders
- Make payments
- Track orders
- View order history
- Receive notifications

### Admin

An admin can:

- Add products
- Update products
- Delete products
- Manage categories
- Manage inventory
- View orders
- Update order status
- Update order status

## 3. MVP Features

The first usable version of the application will support:

1. User registration
2. User login
3. Product browsing
4. Product search
5. Product filtering
6. Product details
7. Add product to cart
8. Remove product from cart
9. View cart

## 4. Advanced Features

The following features will be implemented after the MVP:

- Order management
- Inventory management
- Payment processing
- Notifications
- Kafka event processing
- Redis caching
- API Gateway
- Service discovery
- Circuit breaker
- Retry
- Rate limiting
- Docker
- CI/CD
- Deployment
